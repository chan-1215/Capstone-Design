# Unity 조향 로봇 주행 실험

[메인 README](../README.md) · [실물 서보 조향 주행](driving-with-servo.md)

**작업일: 2026-11-10**

실물 로봇의 반복 시험 부담을 줄이기 위해, 사진과 CAD 치수를 참고한 Unity 가상 트랙·조향 로봇을 만들고 카메라 기반 주행을 실험했습니다.

## 이번에 구현한 내용

- **Unity 2022.3.62f3 · C#:** 기존 트랙을 근사한 두 차선 도로와 앞바퀴 조향 로봇 구성. 직사각형 프레임·바퀴 4개·연결된 카메라로 단순화.
- **카메라:** 지면 높이 15.5cm, 차체 중앙보다 앞쪽 2cm, 아래로 30°. 실제 Unity Camera가 전방 RGB 영상을 생성하며, 시야를 가리던 지지대를 렌즈 뒤로 이동.
- **데이터·학습:** 기존 Unity 주행 기록 489개의 위치·방향을 새 카메라로 다시 렌더링하고, 위치·방향 변형을 더해 2,377장 생성. NumPy MLP(288→64→32→2)로 조향각과 목표 속도 학습.
- **OpenCV:** GaussianBlur → HSV 색 분리 → 노란 경계·흰 점선 윤곽 검출 → 점선 연결 표시. 노란 경계를 가로지르는 연결은 제외.
- **실행 화면:** 실제 카메라 영상에 노란 경계·하늘색 점선·초록 추적 경로를 표시. C키로 표시·숨김, Space/Esc로 정지.

## 주행과 인식 표시의 구분

```text
Unity 카메라 RGB ┬→ 색 분포 특징 → 학습 MLP → 조향각·목표 속도 → 차량 이동
                └→ OpenCV 차선 검출 → 영상 위 경계·점선·추적 경로 표시
```

**현재 조향은 학습 모델이 담당하며, OpenCV 경로는 인식 확인용입니다.**
OpenCV 선을 직접 따라가는 제어기나 저장된 주행 경로 재생 방식은 아닙니다.
모델에는 표시선을 그리지 않은 원본 영상을 넣습니다.
OpenCV에서 점선이 부족하면 경로 미확인으로 표시합니다.

## 검증 결과

| 출발 조건 | 결과 | 시뮬레이션 시간 |
| --- | --- | --- |
| 1차선 출발 | 연속 2바퀴 완료 | 80.62초 |
| 2차선 출발 | 연속 2바퀴 완료 | 92.23초 |

두 시험 모두 교사 조향으로 전환하지 않았습니다. 검증 이미지의 평균 조향 오차는 약 0.98°였습니다.
학습·검증은 원본 시드와 차선 그룹으로 분리했고, 같은 원본의 변형 이미지는 같은 그룹에 묶었습니다.

**검증 범위:** 같은 가상 트랙의 두 출발 조건에서 확인한 결과입니다.
트랙 크기·일부 치수는 사진 기반 추정이며, 차량은 타이어 미끄러짐을 구현하지 않은 운동학 모델입니다.
실물 로봇 성능이나 새 트랙에서의 일반화를 입증한 결과는 아닙니다.
