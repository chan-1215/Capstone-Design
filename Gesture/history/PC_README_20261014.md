# Gesture PC: gestures and persons

PC-webcam-only copy of the gesture recognizer from `Lee/gesture/`. The
`gesture_recognition_module.py`, `hand_utils.py`, and `gesture_knn_model.npz`
files are unchanged copies. `run_webcam.py` is the Windows/PC camera adapter.
`person_detection.py` adds COCO-pretrained YOLOv8n-seg person segmentation. The
current PC stage displays persons and gestures from the same webcam. It
does not yet associate a hand with a particular person, detect a crosswalk,
or decide whether the vehicle should move. There are no robot commands.

## Setup (PowerShell)

```powershell
cd 'C:\Users\a\Capstone-Design\Gesture PC'
uv python install 3.11
uv venv --python 3.11 .venv
uv pip install --python .venv\Scripts\python.exe --index-url https://download.pytorch.org/whl/cpu torch==2.8.0 torchvision==0.23.0
uv pip install --python .venv\Scripts\python.exe --excludes opencv-excludes.txt -r requirements.txt
```

The exclusion keeps MediaPipe's `opencv-contrib-python` as the only `cv2`
wheel. Ultralytics' metadata requests `opencv-python`, but the contrib
wheel supplies the required OpenCV functions; `uv pip check` may report
that metadata requirement as missing. CPU PyTorch is the tested baseline.

## Run

```powershell
& '.venv\Scripts\python.exe' run_webcam.py
```

Press `q` or Esc to close the webcam window. If camera 0 is unavailable, try
`--camera 1`. `--mirror` mirrors the **input** before recognition; use it only
when needed because it can change how gestures compare with the saved model.
For a 60-frame headless camera/model check, run `run_webcam.py --check`.
Close the current Gesture PC window before running the check or another
instance. A Windows camera guard rejects duplicate instances for the same
camera index; other camera applications still need to release the device.

The default YOLOv8n-seg weights download once to `models/yolov8n-seg.pt` on
first use. Subsequent inference runs locally. The green contours follow
each detected person's visible silhouette instead of a rectangular box;
the preview also shows person confidence, count, inference
time, result age, and preview FPS. The original gesture labels remain.
The model returns one mask per detected person. Full-resolution mask
postprocessing maps its outline into the camera image; the input remains
320 pixels, so fine hair/finger boundaries are approximate. It outlines
visible clothes and body regions, not hidden anatomy.

## Processing limits

YOLO runs in one background thread, at most once per 0.2 seconds, with
320-pixel inference input and two PyTorch CPU threads. The pending frame
is replaced with the newest webcam image, so a slow detector does not
build a frame backlog. Detection results older than one second are shown
as `stale` and their outlines are hidden. The person-only class filter affects
returned detections; it does not eliminate the neural network's full
forward pass. Input size and detection interval are the load controls.

```powershell
# Compare against the original gesture-only workload.
& '.venv\Scripts\python.exe' run_webcam.py --gesture-only
# Inspect smaller/distant persons with higher resolution and a slower interval.
& '.venv\Scripts\python.exe' run_webcam.py --person-imgsz 640 --person-interval 0.4
```

`--person-confidence` defaults to 0.5. Tune it against real positive and
negative examples; a high score is not proof that every person is detected.

The model contains 256 labeled 30-frame hand sequences (`stop`, `go`, and
`unknown`). The displayed `Dist` is a feature distance, not a confidence
percentage. `Gesture` may hold the previous valid label briefly to avoid
flicker. No frame, video, or recognition log is saved by this runner.
